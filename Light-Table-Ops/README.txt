Light Table Ops  ·  Lively Wallpaper  ·  von E11iot  ·  English version below
==============================================================================

Installieren
  1. Lively Wallpaper öffnen, die Zip-Datei ins Lively-Fenster ziehen (oder "+" -> Datei wählen).
  2. Wallpaper je Bildschirm zuweisen (eine Datei für alle Monitore, jede Instanz merkt sich ihr Layout).
  3. Beim ersten Start fragt der Assistent nach dem Ort. ⚙ oben rechts öffnet ihn jederzeit wieder.
  Weitere Einstellungen: in Lively beim Wallpaper auf "Anpassen" (Beschriftungen dort auf Englisch).

Wichtig für Klicks: In Lively unter Einstellungen -> Wallpaper -> "Wallpaper-Eingabe" auf "Maus" stellen.
  Klicks erreichen das Wallpaper nur auf freien Desktopflächen.

Layout
  FULL / HALF / STRIP: ganze freie Fläche, halbe Fläche oder schmaler Streifen (rechts, links oder unten).
  Icon-Zone: Spalten, Zellbreite und -höhe in Lively; Feinjustage mit ✎ (Griffe ziehen).
  Paneel anklicken -> Detail öffnet sich, das Layout schiebt sich (aus dem Streifen wird die halbe Fläche).
  ◻ FULL im Detail = ganze Fläche, ✕ CLOSE = zurück. Die vier Quadrate unten wechseln die Hauptansicht:
  Karte · System · Wetter/METAR · Flüge.

Karte: Vektor (OpenFreeMap) oder Satellit (Esri, nur privat), UTMREF-Raster, Regenradar (RN), Flugzeuge (AC).
  Mausrad = Zoom, Ziehen = verschieben, ⌂ = zurück zum Ort. Flugzeug anklicken: Details, Spur und Höhenprofil.
  DWD-Warnungen (ab "markant" oder Gewitter) erscheinen groß in der Mitte, ✕ blendet sie aus.

Flugradar: braucht einen eigenen ADS-B-Proxy (adsb.php liegt bei, Anleitung in PROXY-HOSTING.txt).
  Wetter, METAR/TAF, Regenradar und Warnungen laufen ohne Proxy direkt.

Optional: Bridge-Ops-Sensor 2.0 (eigene Zip, nur Windows) liefert Last und Takt je Thread, Top-Prozesse,
  Laufwerke (Belegung, Lese-/Schreibrate, Aktivität), VRAM, GPU-Temperatur, Uptime und Netz am richtigen Adapter.
  Ohne Sensor zeigt die System-Ansicht Lively-Werte, die Thread-Kacheln sind dann simuliert (so gekennzeichnet).

Light Table Ops  ·  Lively Wallpaper  ·  by E11iot
==============================================================================

Install
  1. Open Lively Wallpaper and drag the zip file into the Lively window (or "+" -> choose file).
  2. Assign it to each screen (one file for all monitors, each instance remembers its own layout).
  3. On first start the setup wizard asks for your location. ⚙ at the top right opens it again anytime.
  More settings: "Customise" on the wallpaper in Lively.

Clicks: in Lively settings -> Wallpaper -> "Wallpaper input" choose "Mouse".
  Clicks only reach the wallpaper on empty desktop areas.

Layout
  FULL / HALF / STRIP: the whole free area, half of it, or a narrow strip (right, left or bottom).
  Icon zone: columns, cell width and height in Lively; fine-tune with ✎ (drag the handles).
  Click a panel -> its detail opens and the layout shifts (a strip grows to half width).
  ◻ FULL in the detail = whole area, ✕ CLOSE = back. The four squares at the bottom switch the main view:
  map · system · weather/METAR · flights.

Map: vector (OpenFreeMap) or satellite (Esri, private use only), UTMREF grid, rain radar (RN), aircraft (AC).
  Wheel = zoom, drag = pan, ⌂ = back to your place. Click an aircraft: details, track and altitude profile.
  DWD warnings (from "moderate" or any thunderstorm) appear large in the center, ✕ hides them.

Flight radar: needs your own ADS-B proxy (adsb.php included, guide in PROXY-HOSTING.txt).
  Weather, METAR/TAF, rain radar and warnings work directly without a proxy.

Optional: Bridge-Ops-Sensor 2.0 (separate zip, Windows only) adds load and clock per thread, top processes,
  drives (usage, read/write rate, activity), VRAM, GPU temperature, uptime and network on the right adapter.
  Without it the system view uses Lively's values and the thread tiles are simulated (marked as such).
