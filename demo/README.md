# Light Table Ops – browser demo

GitHub shows this folder as code only. **Run it here: [e11i0t09.github.io/Light-Table-Ops/demo](https://e11i0t09.github.io/Light-Table-Ops/demo/)**

Options (append to the URL): `?mode=full|half|strip` · `&view=map|sys|wx|flt` · `&proxy=<your adsb.php URL>` for the flight radar.

Live data for Edinburgh, simulated system-sensor values and placeholder desktop icons. The real wallpaper is in [`../Light-Table-Ops`](../Light-Table-Ops).
